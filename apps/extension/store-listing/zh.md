## Name

fenshot: 国际象棋棋盘一键转 FEN

## Short description

国际象棋截图一键转 FEN：读取任何网页上的棋盘，还能从着法列表导入整盘对局。完全在你的设备上运行。

## Detailed description

新功能：在 chess.com 和 Lichess 上添加“在 Kibitzo 上分析”按钮。只需开启
一次，每盘已结束的对局都会在 Game Review（复盘，chess.com）下方
或对局面板中（Lichess）多出一个按钮，一键在免费分析棋盘上打开。
可选功能，默认关闭，由你决定是否开启。

整盘对局：在 chessgames.com、Lichess、chess.com 文章或博客上，
一键读取完整对局并打开复盘。

把你看到的任何国际象棋棋盘变成可分析的局面。任何网页，一键搞定。

在看 YouTube 视频、读 PDF 棋书、刷博客或 chess.com 文章？点击 fenshot 图标，它会读取屏幕上的棋盘，把局面交给你。

你能得到什么
• 在 Kibitzo 上分析：局面打开后，教练用通俗的语言为你讲解
• 在 Lichess 上打开：直接进入分析棋盘
• 复制 FEN：粘贴到任何地方

不只是局面，还有整盘对局
当网页以着法列表的形式展示对局时（chessgames.com、Lichess、chess.com 文章、博客），fenshot 会找到它，检查每一步是否合法，并让你在小棋盘上逐步回放。一键即可在 Kibitzo 或 Lichess 上打开完整对局，或复制 PGN。一个网页上有多盘对局？逐盘翻看即可。

隐私至上的设计
• 只在你点击图标时读取网页，而且只读取当前标签页
• 可选的分析按钮只在 chess.com 和 Lichess 上运行，只在你开启后生效，并且只添加一个链接：对局进行中绝不读取你的着法
• 神经网络 100% 在你的设备上运行，不上传任何内容
• 无需账号，没有统计分析，没有跟踪
• 开源（MIT）：github.com/scoriiu/fenshot

拿不准时如实告诉你
支持 Lichess 和 chess.com 的各种主题、书中的棋局图以及大多数棋子样式。棋盘难以识别时，fenshot 会直接告诉你，而不是瞎猜，并打开编辑器让你修正格子。

由 Kibitzo（kibitzo.com）团队打造，使用与 Kibitzo 导入局面相同的引擎。
